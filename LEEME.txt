TU GASFÍTER — Landing page (maqueta avanzada para arrancar)
============================================================

CONTENIDO
  index.html        → la página completa (HTML + CSS + JS, sin frameworks)
  img/              → fotos del cliente ya optimizadas para web

CÓMO PROBARLA
  Abre index.html en el navegador (doble clic). Todo funciona sin servidor.

ANTES DE PUBLICAR — reemplazar estos placeholders:
  1) Teléfono / WhatsApp: buscar "56912345678" en index.html y cambiarlo
     por el número real (formato sin +, sin espacios). Aparece en: WhatsApp
     flotante, CTA del hero, sección contacto y footer.
  2) Formulario: en el <form> reemplazar TU_WEB3FORMS_ACCESS_KEY por tu
     access key de web3forms.com. Mientras no la pongas, el formulario
     muestra el mensaje de éxito (modo demo) sin enviar nada.
  3) Email de contacto: "contacto@24-7gasfiter.cl" (footer) si corresponde.
  4) Color: el <body data-palette="rojo"> define la paleta. Opciones:
     rojo · azul · verde · naranjo · cian · purpura. El selector inferior
     sirve para que el cliente elija; una vez decidido, fija el data-palette
     y borra el bloque <div class="palette-bar"> + la sección "Selector de
     paleta" del JS.

FOTOS
  Las 8 tarjetas de "Servicios" usan íconos (consistente y liviano). Para
  poner una foto real en una tarjeta, avísame qué foto va en qué servicio.
  El hero, "Nosotros", "Respaldo" y el mapa ya usan fotos del cliente.

DESPLIEGUE (Cloudflare Pages)
  Sitio estático puro: sube esta carpeta como proyecto de Pages
  (build command vacío, output dir = raíz). O git push al repo conectado.

CONTENIDO EDITABLE
  Servicios, detalles, pasos, comunas y FAQ están en el bloque <script>
  al final del index.html, en constantes fáciles de editar (SERVICIOS,
  DETALLES, PASOS, COMUNAS, FAQS).
